# 机型情况

每一行都要有证据。“验证到”一栏的级别见 [TESTING.md](TESTING.md)；证据目录由 `tools/evidence.py` 生成，规则见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

状态的意思：

- **维护者在用**：维护者自己的手机，日常跑着，每个版本发布前在它上面过一遍。
- **贡献者验证**：别人提交了证据，维护者核对过证据，但手上没有这款手机。
- **部分可用**：能用，但有写明的限制。
- **不支持**：试过，写明卡在哪里。也是有用的结果。

这两台是在这套取证办法定下来之前适配的，下面写的是维护者实际做过和看到的，按新办法的证据目录还没有补齐。补齐之前，“验证到”一栏不填级别。

## Redmi Note 11 5G

- 无线调试可用，配对一次后网关重启、换 Wi-Fi 都能自己恢复音频服务。
- 通话：`VOICE_DOWNLINK` 录对方，写“通话送话”设备，按安卓标准做法即可。0.43.0 上打进、打出各一通，日志里两个方向都有声音、没有丢帧。
- MIUI 的几件事：安装新应用要在屏幕上点确认；每条外发短信都弹确认框，所以网关要当默认短信应用；重启和更新后收回“接听电话”，网关用 shell 补回；权限页里另有一层自己的开关；“读取通知类短信”要在 MIUI 权限页里单独允许。
- 双卡双待单通：一张卡通话时，另一张卡的来电由系统按占线处理。
- 读不到卡的服务状态（系统不给），网关改看是否注册到运营商网络。
- 没验证或没记录的：按新办法的 L2 听感确认、L3。

## 华为 Mate 40 RS（NOP-AN00）

- 开发者选项里没有无线调试，走 `adb tcpip 5555`。重启后调试端口关闭，要重新连电脑开一次，在那之前通话没有声音。
- 通话音频和默认路径不同，细节在 `BridgeMain.java` 的 `HISILICON_UPLINK` 注释里：录音用 `VOICE_CALL` 立体声；送话音轨必须是手机上唯一在播的音轨；录音要先于送话音轨打开；送话音轨不能断流。
- 省电管理：必须在“应用启动管理”里把网关改成手动管理并三项全开，否则熄屏十几秒就被冻结并断网。换包名或重装成新应用后要重新设。
- 系统把应用自己的普通日志过滤掉了，`gateway.log` 基本是空的，看 `bridge.log`。
- 熄屏或不在前台时系统只给小核，语音合成慢好几倍；网关需要性能时会自己点亮屏幕到前台。
- 没验证的：0.43.x 上的 L2 听感确认、短信、L3。
